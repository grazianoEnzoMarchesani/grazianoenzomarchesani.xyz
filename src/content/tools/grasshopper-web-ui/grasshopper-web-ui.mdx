A universal web interface for Grasshopper: interactive 3D geometry
visualisation and manipulation through a standard browser, with the
solver still running in Rhino. It removes the platform wall between
Windows and macOS that splits most computational design teams in two.

The most starred of my repositories, and the one people write to me
about.
