The methodological framework used for environmental modelling in the LIFE
A_GreeNET project: Rhinoceros, Grasshopper and the Morpho plugin chained
into a standard sequence, so that two people modelling the same street
get the same input file.

Written because the hardest part of urban microclimate simulation is not
the physics — it is making sure the geometry, the materials and the
boundary conditions were built the same way twice.
