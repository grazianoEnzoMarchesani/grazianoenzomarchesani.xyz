# Second brain — indice

Memoria persistente del progetto. Va letta a inizio sessione e mantenuta a fine sessione (vedi skill `update-brain`).

Due tipi di file:
- **Decisione** (stato attuale, si riscrivono: la voce vecchia sparisce quando ne arriva una nuova che la contraddice — mai storico dentro).
- **Log** (cronologico, si aggiunge soltanto, mai riscritto).

## File

- [constraints.md](constraints.md) — vincoli fondamentali del progetto (performance, responsive, estetica) e regole operative per chi lavora sul codice. *Decisione.*
- [stack.md](stack.md) — stack tecnico scelto e perché. *Decisione.*
- [content-plan.md](content-plan.md) — cosa deve contenere il sito, migrazione dal vecchio sito. *Decisione.*
- [design.md](design.md) — direzione visiva/estetica. *Decisione.*
- [blocchi-articoli.md](blocchi-articoli.md) — immagini, video, LaTeX e grafici dentro il corpo degli articoli di Fields. *Decisione.*
- [fields-spiral.md](fields-spiral.md) — l'animazione 3D della pagina Fields (la spirale scroll-driven). *Decisione.*
- [session-log.md](session-log.md) — cronologia breve, una voce per sessione. *Log.*
